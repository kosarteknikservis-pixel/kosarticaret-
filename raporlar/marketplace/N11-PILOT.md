# N11 pilot

Kaynak: [N11 Ürün Yükleme](https://developer.n11.com/documentation/n11-marketplace-entegrasyonu/urun-yukleme/)

Kurallar uygulanan:
- stok `quantity` >= 1 (0 yasak)
- `listPrice` >= `salePrice`
- HTTPS görsel, zorunlu kategori attribute
- `shipmentTemplate` birebir panel şablon adı
- Koşar marka gönderilmez
- Başlık = ürün adı (spam yok)
