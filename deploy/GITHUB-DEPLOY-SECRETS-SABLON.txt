--------------------------------------------------------------------------------
4) DEPLOY_SSH_KEY  (PRIVATE key - sadece GitHub Secret'a)
--------------------------------------------------------------------------------
ONEMLI: Her proje icin AYRI key uretin; projeler karismasin.

ADIM A - Windows'ta yeni key (PowerShell):

  mkdir C:\deploy-keys\kosarticaret -Force
  ssh-keygen -t ed25519 -C "github-deploy-kosarticaret" -f C:\deploy-keys\kosarticaret\id_ed25519 -N '""'

  NOT: PowerShell'de -N "" CALISMAZ. Mutlaka -N '""' kullanin.
  Alternatif (CMD):
  cmd /c "ssh-keygen -t ed25519 -C github-deploy-kosarticaret -f C:\deploy-keys\kosarticaret\id_ed25519 -N \"\""

  Olusan dosyalar:
    id_ed25519      -> PRIVATE (GitHub DEPLOY_SSH_KEY)
    id_ed25519.pub  -> PUBLIC (sunucuya)

ADIM B - Public key'i sunucuya ekle:

  Yontem 1 (DirectAdmin):
    Hesap Yoneticisi -> SSH Keys -> Import Key
    id_ed25519.pub icerigini yapistir

  Yontem 2 (SSH ile):
    notepad C:\deploy-keys\kosarticaret\id_ed25519.pub
    Icerigi sunucuda ~/.ssh/authorized_keys dosyasina ekle

ADIM C - Private key'i GitHub'a ekle:

  notepad C:\deploy-keys\kosarticaret\id_ed25519
  TUMUNU kopyala (-----BEGIN ... KEY----- ile -----END ... KEY----- dahil)
  GitHub -> Settings -> Secrets -> New secret
  Name: DEPLOY_SSH_KEY
  Value: yapistir -> Add secret

ADIM D - Test (PC'den):

  ssh -i C:\deploy-keys\kosarticaret\id_ed25519 KULLANICI@IP "echo OK"

  OK yazarsa dogru. Sonra GitHub Actions tekrar calistir.

Private key dosya yolu (bu PC'de sakla, GitHub'a yukle):
C:\deploy-keys\kosarticaret\id_ed25519

5) GOOGLE_SEO_CREDENTIALS_JSON  (GSC panel kelime verisi - bir kez)
--------------------------------------------------------------------------------
Nereden alinir:
  - Yerelde B1 icin kullandiginiz Google service account JSON dosyasinin TAM icergi
  - Ornek yol (PC): C:\Users\PC\.config\kosar-seo\gsc-ga4-service-account.json

GitHub -> Settings -> Secrets -> New secret
  Name : GOOGLE_SEO_CREDENTIALS_JSON
  Value: JSON dosyasinin tumu (tek satir olabilir)

Deploy her seferinde sunucuya yazar:
  kosar/storage/app/private/gsc-service-account.json

Panel kelime listesi: gunluk cron (05:05) + her deploy sonrasi otomatik cekilir.
